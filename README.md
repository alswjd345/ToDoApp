# 📝 WPF TODO 앱

## 📌 프로젝트 소개

WPF를 사용하여 간단한 TODO 리스트를 구현한 프로젝트입니다.
사용자는 할 일을 추가하고, 체크박스를 통해 완료 여부를 표시하며, 선택된 항목을 삭제할 수 있습니다.

---

## 🛠 사용 기술

* C#
* WPF (.NET)

---

## 🚀 주요 기능

### ✔ 할 일 추가

* 입력창에 내용을 입력 후 "추가" 버튼 클릭
* ListBox에 체크박스 형태로 추가

### ✔ 완료 체크

* 각 항목은 CheckBox로 구성
* 체크 시 완료 표시 가능

### ✔ 선택 삭제

* 체크된 항목만 선택적으로 삭제

---


### ⚠ 예외 처리

* 입력값이 비어있을 경우 추가 불가
* 체크된 항목이 없을 경우 삭제 불가

---

## 📸 화면 구성

* 입력창 + 추가 버튼
* TODO 리스트 (CheckBox)
* 선택 삭제 버튼
